# 磁芯测试数据标签 —— 交接说明

> 现状：**原型**，能在本机标签机上打出来，**还没接入工位软件，也没发版**。
> 代码：`scripts/core_label_print.py`；打印机的坑见 `doc/标签打印机.md`（必读）。

## 这是什么

磁芯测完后，打一张小标签贴在磁芯上，现场不用查系统就能看到这颗磁芯的测试结果。标签上有：

| 位置 | 内容 |
|---|---|
| 顶部黑条 | 公司 / 产线 / 工位（取工位软件的 `config.json`，也可命令行指定） |
| 左上 | 磁芯号（大字）+ 判定框（PASS 黑底白字，FAIL 白底黑框） |
| 左中 | 产品编号、测试时间 |
| 右上 | 二维码（内容见下面「待定事项」） |
| 下方 | 全部测试值，3 列自适应排版：Turn / Lx / Lk / Q / Cx / Dcr / 等效n |

来历：2026-09-11 业主在本机试做，比较了 45×30、40×26、35×22 三种尺寸，**最后想用 45×30**。
原型当时只放在临时目录、后来被清掉，2026-10-24 从会话记录原样还原并整理成现在的脚本，排版与原型一致。

## 怎么跑

用系统 Python 3.11 或 miniforge 的 `autotest` 环境都行（要 Pillow、reportlab，真打印还要 pywin32）。
数据取工位软件 `results/` 目录下的测试 CSV。**不加 `--print` 只出预览图，不会打印。**

```bash
# 取 CSV 里最后一条合格记录，出 45×30 预览图（默认存到 ./core_label_preview/）
python scripts/core_label_print.py results/ZZ-H2500011-磁芯检_xxxx.csv

# 指定磁芯号、指定顶部工位文字
python scripts/core_label_print.py <CSV> --core 1767 --station 汉润/智子专线/磁芯检

# 三种尺寸的对比样张
python scripts/core_label_print.py <CSV> --samples

# 真打印：本机现在装的是 70×130 卷纸，标签画在左上角并带裁切框，可剪下来比对磁芯大小
python scripts/core_label_print.py <CSV> --print

# 换成 45×30 卷纸后直接打
python scripts/core_label_print.py <CSV> --paper 45x30 --print
```

常用参数：`--size` 标签尺寸（默认 45x30）、`--paper` 打印机里的卷纸尺寸（默认 70x130）、
`--config` 工位软件的 config.json、`--qr-prefix` 二维码前缀、`--out` 预览图目录、`--printer` 打印队列名。

## 打印机（必看 `doc/标签打印机.md`）

- Windows 里叫 `EZSCAN E75`，实际机器是 **APRT 芝润（AY-D33）**，驱动对不上。
- **只能 TSPL 指令 RAW 直发**，脚本已经这么做（复用 `scripts/label_print.py` 的 `tspl_job` / `send_raw`）。
  千万别用 Word、浏览器等走驱动打印：会乱码、不停走纸，只能清队列并给打印机断电。
- 位图每行宽度必须向下取 8 的整数倍，多 1 个点整张图就逐行错位（`lp.bitmap_bytes` 已处理）。
- 先打 1 张核对实物，再批量。

## 已知问题与待定事项（接手时先跟业主确认）

1. **二维码里放什么**：原型放的是 `soaipower.com/t/<磁芯号>`。但线上扫码页 `/t/<码>` 现在只认 9 位成品码，
   扫磁芯号会显示「查不到这个码」。可选：
   - 扫码页加一种「磁芯号」查询（显示这颗磁芯的测试记录）；
   - 或者二维码只放磁芯号本身，供扫码枪录入；
   - 注意：磁芯号目前**不是全局唯一**（同一个号东磁、汉润都测过，属于同一颗磁芯；跨批次是否会重号待确认）。
2. **二维码大小**：45×30 上二维码约 9.4 mm、每格 3 个点，应该能扫；40×26 和 35×22 每格只有 2 个点，
   可能扫不出，**用前要实测**。为了二维码更大，静区只留 2 格（成品码标签是 4 格）。
3. **标签纸**：本机现在装的是 70×130 卷纸，45×30 要另外采购卷纸，到货后用 `--paper 45x30` 直接打。
4. **数据来源**：现在读工位本地的测试 CSV。接入工位软件时，可以在测试完成后直接用这条记录打印（不必再读 CSV）。
5. **磁芯流水码**：原型曾试过给每颗磁芯自动发 4 位流水码（`backend/serial_code.py`，提交 `dba76c0`），
   业主后来决定不用（v1.7.5 删除，「二维码是给成品的」）。现在标签上印的是原来的磁芯编号。

## 建议的下一步

1. 跟业主确认上面第 1、3 点。
2. 在本机打几张 45×30 实测：字能不能看清、二维码能不能扫。
3. 接入工位软件（autotest）：例如测试页加「打印标签」按钮，或在设置里开「合格后自动打印」。
   后端加一个接口，复用 `core_label()` 排版和 `lp.send_raw()` 发送；打印失败不能影响测试结果和数据上传。
4. 工位软件发版要业主逐项点头（流程见 `CHANGELOG.md` 与发版脚本）。
